Project Documentation

1. Project Overview

PedalPulse is a web-based database application designed to organize and explore historical Citi Bike trip information.

Our project uses cleaned Citi Bike data from September 2026, containing 106,294 trip records and 222 bicycle stations.

The application interface provides webpages for adding, deleting, and updating trip information.

3. Software Requirements

  • Modern web browser (Chrome, Safari, or Firefox)
  • HTML5 and CSS3
  • PostgreSQL database management system
  • pgAdmin 4 for database administration
  • Local server for future backend integration

4. Hardware Requirements

  • Computer capable of running a modern browser
  • Recommended: 8 GB RAM
  • Recommended: 12 GB available disk space
  • Internet connection for accessing GitHub

5. Setup Instructions

  1. Download the PedalPulse project files.
  2. Extract the project ZIP folder.
  3. Install PostgreSQL and pgAdmin 4 if database administration is required.
  4. Restore the PedalPulse PostgreSQL database from the provided backup if available.
  5. Open index.html in a web browser to view the website interface.

For this HTML/CSS interface prototype, no backend server is required. Opening index.html locally displays the website.

6. User Guide

Home: Read the project introduction, dataset information, and database overview.

Add Trip: Enter the information for a new bicycle trip using the form provided.

Delete Trip: Enter the unique Ride ID of a trip that should be deleted.

Update Trip: Enter an existing Ride ID and provide the information that should be changed.

Documentation: Review project information, requirements, setup instructions, and webpage descriptions.

Note: The Add, Delete, and Update forms are interface demonstrations. Database changes require backend integration, which is not included in this HTML/CSS prototype.

7. Dataset Source
